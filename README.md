## ▶️ How to Run

### Compile

```bash
g++ filename.cpp -o output
```

### Run on Windows

```bash
output.exe
```

### Run on Linux / macOS

```bash
./output
```

### Example

```bash
g++ hello.cpp -o hello
```

Then:

```bash
hello.exe
```
